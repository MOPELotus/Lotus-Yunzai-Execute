# 代操作与批量执行

Lotus-Yunzai 的内置模块。通过已连接的机器人会话，由宿主验证通过的主人发起。

```text
#代 @用户 #体力2
#代 123456789 #体力2
#执行 @用户 #体力
#执行 全员 #体力
#执行 123456789,987654321 群=12345678 间隔=5 静默=关 -- #体力2
#执行 全员 群=全部群 间隔=5 静默=开 -- #体力
#执行 123456789 群=私聊 -- #体力
```

默认沿用当前会话，目标按顺序执行，间隔默认 5 秒。`群=本群`、`群=私聊`、`群=全部群` 和指定群号均可用。私聊需指定用户。指令前的提及选择执行人，指令内的提及作为指令参数。回复默认送达目标会话，`静默=开` 抑制通过授权目标事件发出的回复。

旧格式 `#execute in:here as:123456789 gap:5 hold:false run:#体力2` 仍可使用。`in:@s` 表示私聊，`in:@e` 表示全部群，`as:@a` 表示全员。

宿主按目标身份、会话和指令重新检查授权。批量执行期间，每个机器人同一时间只接受一批。连接失效或模块卸载时，停止派发剩余任务。执行汇总列出已处理、异常和未命中或被拒绝的数量。具体业务结果以各指令的实际回复为准。

使用 `bun test` 运行命令解析和批处理测试。

命令语法与批量执行源自 MOPELotus 的 Lotus-ReFactor `apps/execute.js`、`services/pluginBridge/delegate.js` 与 `docs/execute.md`。参见 [源提交](https://github.com/MOPELotus/Lotus-ReFactor/commit/b2598f4f9db730aaf42050aadcc13014025da974) 和 [原许可](LICENSE)。
